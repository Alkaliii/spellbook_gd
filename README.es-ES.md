# spellbook
*Una colección de shaders para Godot.*

Este repositorio contiene shaders para crear VFX junto con demostraciones y documentación adicional sobre su uso. 
No soy bueno escribiendo código y aún peor con shaders, por favor disculpen todas las implementaciones deficientes o no óptimas.

## ¿Qué puedo usar?
Este repositorio está bajo la [Licencia MIT](https://github.com/Alkaliii/spellbook_gd/blob/master/LICENSE), pero algunas partes pueden regirse por otras licencias. Pero más o menos, puedes usar todo lo que encuentres aquí de acuerdo con su respectiva licencia (que debería ser MIT).
Los créditos son agradecidos, pero no obligatorios.
